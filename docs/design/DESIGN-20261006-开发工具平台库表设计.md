## 1. 设计总览

### 1.1 存储分层

| 存储 | 内容 | 访问方式 |
|------|------|----------|
| PostgreSQL（框架主库） | 模板组、模板文件、模板版本、数据源、生成记录（**5 张表**） | MyBatis-Plus，Manager 层 |
| 服务器临时目录 | 渲染沙箱 `${java.io.tmpdir}/carlos-devkit/{requestId}/` | 请求内 `try/finally` 创建与删除，**非持久化** |
| 生成产物 | 不落库、不落盘：内存 → zip 流 | 直接回给浏览器 |

> **不做**：产物持久化（如需二次下载，二期把 zip 存 OSS，本设计预留 `dev_generate_record.oss_object_key` 字段位，一期不启用）。

### 1.2 命名与字段规范（对齐框架既有约定，同 `monitor_*`）

- 表名小写下划线，统一前缀 `dev_`；
- 主键 `id BIGINT`（MyBatis-Plus `ASSIGN_ID` 雪花 ID），无统一 BaseEntity，公共字段各表平铺；
- 公共审计字段：`create_by BIGINT`、`create_time TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`、`update_by BIGINT`、`update_time TIMESTAMP`；
- 逻辑删除 `is_deleted SMALLINT NOT NULL DEFAULT 0`（实体 `Boolean` + `@TableLogic`）；
- 枚举字段：状态类用 `SMALLINT`，类型编码类用 `VARCHAR`（字典编码字符串）；
- 索引命名：唯一 `uk_表_字段`、普通 `idx_表_字段`；
- **不使用外键、不使用存储过程**；表与字段注释：`COMMENT ON TABLE/COLUMN ... IS '...'`；
- 逻辑删除与唯一性冲突的场景使用 **PG 部分唯一索引** `WHERE is_deleted = 0`。

### 1.3 表清单

| # | 表名 | 说明 | 主要增长量级 |
|---|------|------|--------------|
| 1 | `dev_template_group` | 模板组（一组模板的元数据 + 字段识别规则） | 十级 |
| 2 | `dev_template` | 模板文件（含在线编辑的正文） | 千级（内置 107 + 自定义） |
| 3 | `dev_template_version` | 模板版本历史（每次保存落一版） | 万级/年 |
| 4 | `dev_datasource` | 受管数据源（密码 SM4 加密） | 百级 |
| 5 | `dev_generate_record` | 生成记录（产物摘要，不含产物） | 万级/年 |

### 1.4 ER 关系（文字描述）

```
dev_template_group 1───n dev_template 1───n dev_template_version
        │
        └── 逻辑关联 dev_generate_record.template_group_id（不建外键）

dev_datasource  1───n dev_generate_record（逻辑关联 ds_id，仅代码生成）
```

## 2. 表结构

### 2.1 `dev_template_group` 模板组

对应原 `template.xml` 的 `<name>` / `<describe>` / `<logicDeleteFields>` / `<versionFields>` / `<commonFields>`，以及模板组目录本身的元信息。

```sql
CREATE TABLE dev_template_group
(
    id                  BIGINT       NOT NULL,
    group_code          VARCHAR(64)  NOT NULL,
    group_name          VARCHAR(128) NOT NULL,
    description         VARCHAR(512),
    template_type       SMALLINT     NOT NULL,
    tech_stack          VARCHAR(32),
    db_type             VARCHAR(16),
    template_root       VARCHAR(64)  NOT NULL DEFAULT 'template',
    logic_delete_fields VARCHAR(512),
    version_fields      VARCHAR(512),
    common_fields       VARCHAR(1024),
    built_in            BOOLEAN      NOT NULL DEFAULT FALSE,
    status              SMALLINT     NOT NULL DEFAULT 1,
    sort_num            INT          NOT NULL DEFAULT 0,
    remark              VARCHAR(512),
    create_by           BIGINT,
    create_time         TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_by           BIGINT,
    update_time         TIMESTAMP,
    is_deleted          SMALLINT     NOT NULL DEFAULT 0,
    CONSTRAINT pk_dev_template_group PRIMARY KEY (id)
);

CREATE UNIQUE INDEX uk_dev_template_group_code
    ON dev_template_group (group_code) WHERE is_deleted = 0;
CREATE INDEX idx_dev_template_group_type
    ON dev_template_group (template_type, status);

COMMENT ON TABLE dev_template_group IS '开发工具-模板组';
COMMENT ON COLUMN dev_template_group.id IS '主键（雪花 ID）';
COMMENT ON COLUMN dev_template_group.group_code IS '模板组编码，全局唯一，如 cloud-mybatis';
COMMENT ON COLUMN dev_template_group.group_name IS '模板组显示名，如 微服务MyBatis-Plus';
COMMENT ON COLUMN dev_template_group.description IS '描述';
COMMENT ON COLUMN dev_template_group.template_type IS '模板类型：1=代码生成 2=工程生成';
COMMENT ON COLUMN dev_template_group.tech_stack IS '技术栈编码：MYBATIS/DDD_MYBATIS/ELASTICSEARCH/MONGO/SPRINGBOOT/SPRINGCLOUD/OTHER';
COMMENT ON COLUMN dev_template_group.db_type IS '适用数据库：MYSQL/POSTGRESQL/ANY；工程生成可空';
COMMENT ON COLUMN dev_template_group.template_root IS '物化时模板根目录名，默认 template（对齐原目录结构）';
COMMENT ON COLUMN dev_template_group.logic_delete_fields IS '逻辑删除字段名清单，逗号分隔，如 is_deleted,deleted,del_flag';
COMMENT ON COLUMN dev_template_group.version_fields IS '乐观锁版本字段名清单，逗号分隔，如 version,revision';
COMMENT ON COLUMN dev_template_group.common_fields IS '通用字段名清单，逗号分隔，如 create_by,create_time,update_by,update_time';
COMMENT ON COLUMN dev_template_group.built_in IS '是否内置模板（内置不可删除，仅可停用）';
COMMENT ON COLUMN dev_template_group.status IS '状态：1=启用 0=停用';
COMMENT ON COLUMN dev_template_group.sort_num IS '排序值，越小越靠前';
COMMENT ON COLUMN dev_template_group.remark IS '备注';
COMMENT ON COLUMN dev_template_group.create_by IS '创建人';
COMMENT ON COLUMN dev_template_group.create_time IS '创建时间';
COMMENT ON COLUMN dev_template_group.update_by IS '更新人';
COMMENT ON COLUMN dev_template_group.update_time IS '更新时间';
COMMENT ON COLUMN dev_template_group.is_deleted IS '逻辑删除：0=正常 1=删除';
```

> **字段清单为什么用逗号分隔字符串而不是 JSONB**：这三列只在生成时被 `String.split(",")` 一次性消费，无查询需求；用 `VARCHAR` 可避免引入 JSONB TypeHandler（当前 devkit 引擎是纯 JDBC/POJO，不依赖 MyBatis 的 JSON 映射）。若后续要按字段反查模板组，再升级为 `JSONB` 并配套 TypeHandler。

### 2.2 `dev_template` 模板文件

一个模板组下的**每个文件一行**：`.ftl` 模板（`file_type=1`）与静态资源如 `Dockerfile`、`.gitignore`、`application.yml.ftl`（`file_type=2`）。

```sql
CREATE TABLE dev_template
(
    id               BIGINT       NOT NULL,
    group_id         BIGINT       NOT NULL,
    file_path        VARCHAR(512) NOT NULL,
    file_name        VARCHAR(256) NOT NULL,
    file_ext         VARCHAR(32),
    file_type        SMALLINT     NOT NULL DEFAULT 1,
    loop_flag        BOOLEAN      NOT NULL DEFAULT FALSE,
    content          TEXT,
    content_encoding VARCHAR(16)  NOT NULL DEFAULT 'TEXT',
    file_size        INT          NOT NULL DEFAULT 0,
    md5              VARCHAR(32),
    sort_num         INT          NOT NULL DEFAULT 0,
    status           SMALLINT     NOT NULL DEFAULT 1,
    remark           VARCHAR(512),
    create_by        BIGINT,
    create_time      TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_by        BIGINT,
    update_time      TIMESTAMP,
    is_deleted       SMALLINT     NOT NULL DEFAULT 0,
    CONSTRAINT pk_dev_template PRIMARY KEY (id)
);

CREATE UNIQUE INDEX uk_dev_template_path
    ON dev_template (group_id, file_path) WHERE is_deleted = 0;
CREATE INDEX idx_dev_template_group ON dev_template (group_id, status);

COMMENT ON TABLE dev_template IS '开发工具-模板文件（含在线编辑正文）';
COMMENT ON COLUMN dev_template.id IS '主键（雪花 ID）';
COMMENT ON COLUMN dev_template.group_id IS '所属模板组 ID（dev_template_group.id）';
COMMENT ON COLUMN dev_template.file_path IS '组内相对路径，如 src/main/java/pojo/entity/[base][for].java.ftl；禁止 .. / 绝对路径 / 盘符';
COMMENT ON COLUMN dev_template.file_name IS '文件名（路径末段）';
COMMENT ON COLUMN dev_template.file_ext IS '扩展名，如 ftl/java/xml/yml';
COMMENT ON COLUMN dev_template.file_type IS '文件类型：1=模板(.ftl，需渲染) 2=静态资源(直接拷贝)';
COMMENT ON COLUMN dev_template.loop_flag IS '是否循环渲染（文件名含 [for]，按表逐张生成）';
COMMENT ON COLUMN dev_template.content IS '文件正文；content_encoding=BASE64 时为二进制内容的 Base64';
COMMENT ON COLUMN dev_template.content_encoding IS '正文编码：TEXT=纯文本 BASE64=二进制(如图片/字体)';
COMMENT ON COLUMN dev_template.file_size IS '正文字节数（物化时用于限额校验）';
COMMENT ON COLUMN dev_template.md5 IS '正文 MD5，用于变更检测与物化缓存';
COMMENT ON COLUMN dev_template.sort_num IS '同层级排序值';
COMMENT ON COLUMN dev_template.status IS '状态：1=启用 0=停用（停用则不参与生成）';
COMMENT ON COLUMN dev_template.remark IS '备注';
COMMENT ON COLUMN dev_template.create_by IS '创建人';
COMMENT ON COLUMN dev_template.create_time IS '创建时间';
COMMENT ON COLUMN dev_template.update_by IS '更新人';
COMMENT ON COLUMN dev_template.update_time IS '更新时间';
COMMENT ON COLUMN dev_template.is_deleted IS '逻辑删除：0=正常 1=删除';
```

**与原名占位符的对应关系**（语义完全保留，迁移零成本）：

| 占位符 / 指令 | 出现位置 | 承载字段 |
|---|---|---|
| `[base]` | 文件名 / 路径 | 不存字段，渲染时用 `table.classPrefix` 替换 |
| `[for]` | 文件名 | `loop_flag = TRUE` |
| `[ArtifactId]` / `[Package]` / `[CamelName]` / `[UnderLineName]` | 工程模板路径与文件名 | 不存字段，渲染时按 `ProjectDirectEnum` 替换 |

### 2.3 `dev_template_version` 模板版本历史

每次"保存模板"自动落一版（保存前快照），支持查看与回滚。

```sql
CREATE TABLE dev_template_version

    id          BIGINT       NOT NULL,
    template_id BIGINT       NOT NULL,
    group_id    BIGINT       NOT NULL,
    version_no  INT          NOT NULL,
    file_path   VARCHAR(512) NOT NULL,
    content     TEXT,
    content_encoding VARCHAR(16) NOT NULL DEFAULT 'TEXT',
    file_size   INT          NOT NULL DEFAULT 0,
    md5         VARCHAR(32),
    change_log  VARCHAR(512),
    create_by   BIGINT,
    create_time TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    is_deleted  SMALLINT     NOT NULL DEFAULT 0,
    CONSTRAINT pk_dev_template_version PRIMARY KEY (id)
);

CREATE UNIQUE INDEX uk_dev_template_version_no
    ON dev_template_version (template_id, version_no) WHERE is_deleted = 0;

COMMENT ON TABLE dev_template_version IS '开发工具-模板版本历史';
COMMENT ON COLUMN dev_template_version.template_id IS '模板 ID（dev_template.id）';
COMMENT ON COLUMN dev_template_version.group_id IS '模板组 ID（冗余，便于按组清理与查询）';
COMMENT ON COLUMN dev_template_version.version_no IS '版本号，同一模板内自增';
COMMENT ON COLUMN dev_template_version.file_path IS '保存时的文件路径快照（改名后可追溯）';
COMMENT ON COLUMN dev_template_version.content IS '该版本的正文快照';
COMMENT ON COLUMN dev_template_version.change_log IS '变更说明（保存时用户填写，可空）';
COMMENT ON COLUMN dev_template_version.create_by IS '保存人';
COMMENT ON COLUMN dev_template_version.create_time IS '保存时间';
COMMENT ON COLUMN dev_template_version.is_deleted IS '逻辑删除：0=正常 1=删除';
```

> **保留策略**：默认每模板保留最近 **50** 版（`carlos.devkit.template.max-versions`），超出由定时任务清理（一期可用 `carlos-job` 的 `@ScheduleJob` 注册，或先留 `TODO` 手工清理）。

### 2.4 `dev_datasource` 受管数据源

密码 SM4 加密存储，结构与语义对齐 `monitor_instance`（`CredentialCipher`）。

```sql
CREATE TABLE dev_datasource
(
    id              BIGINT       NOT NULL,
    ds_name         VARCHAR(128) NOT NULL,
    ds_code         VARCHAR(64),
    db_type         VARCHAR(16)  NOT NULL,
    host            VARCHAR(128) NOT NULL,
    port            INT          NOT NULL,
    database_name   VARCHAR(128),
    schema_name     VARCHAR(128),
    username        VARCHAR(128),
    password_cipher VARCHAR(512),
    jdbc_params     VARCHAR(1024),
    read_only       BOOLEAN      NOT NULL DEFAULT TRUE,
    status          SMALLINT     NOT NULL DEFAULT 1,
    remark          VARCHAR(512),
    create_by       BIGINT,
    create_time     TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_by       BIGINT,
    update_time     TIMESTAMP,
    is_deleted      SMALLINT     NOT NULL DEFAULT 0,
    CONSTRAINT pk_dev_datasource PRIMARY KEY (id)
);

CREATE UNIQUE INDEX uk_dev_datasource_name
    ON dev_datasource (ds_name) WHERE is_deleted = 0;
CREATE INDEX idx_dev_datasource_type ON dev_datasource (db_type, status);

COMMENT ON TABLE dev_datasource IS '开发工具-受管数据源（供代码生成器读取表元数据）';
COMMENT ON COLUMN dev_datasource.ds_name IS '数据源名称，如 本地框架库';
COMMENT ON COLUMN dev_datasource.ds_code IS '数据源编码（可空）';
COMMENT ON COLUMN dev_datasource.db_type IS '数据库类型：MYSQL/POSTGRESQL（对齐原 DbTypeEnum）';
COMMENT ON COLUMN dev_datasource.host IS '主机地址';
COMMENT ON COLUMN dev_datasource.port IS '端口';
COMMENT ON COLUMN dev_datasource.database_name IS '库名（原 buildUrl 的 [databaseName]）';
COMMENT ON COLUMN dev_datasource.schema_name IS '默认 schema（PG 专用，MySQL 可空）';
COMMENT ON COLUMN dev_datasource.username IS '用户名';
COMMENT ON COLUMN dev_datasource.password_cipher IS '密码 SM4 密文（EncryptUtil；SM4 未启用时等于明文，生产必须开启）';
COMMENT ON COLUMN dev_datasource.jdbc_params IS '额外 JDBC 参数，如 useSSL=false&serverTimezone=Asia/Shanghai';
COMMENT ON COLUMN dev_datasource.read_only IS '是否只读数据源（仅取元数据）；默认 TRUE';
COMMENT ON COLUMN dev_datasource.status IS '状态：1=启用 0=停用';
COMMENT ON COLUMN dev_datasource.remark IS '备注';
COMMENT ON COLUMN dev_datasource.create_by IS '创建人';
COMMENT ON COLUMN dev_datasource.create_time IS '创建时间';
COMMENT ON COLUMN dev_datasource.update_by IS '更新人';
COMMENT ON COLUMN dev_datasource.update_time IS '更新时间';
COMMENT ON COLUMN dev_datasource.is_deleted IS '逻辑删除：0=正常 1=删除';
```

**安全约定**（与 storage 模块 `secretKey` 相同的三套语义）：

| 场景 | `password` 行为 |
|---|---|
| 列表 / 详情返回 | **不下发密码**，只回 `hasPassword: true/false` |
| 新增 | 必填，`EncryptUtil.encrypt` 后写 `password_cipher` |
| 更新 | `null` / 空串 = **保持原值**；非空 = 覆盖为新密文。**绝不回填密文到前端**（回填即毁数据） |
| 生成时 | 后端按 `dsId` 取出密文 → `decrypt` → 构造连接，明文不出 `CredentialCipher` 边界、不进日志 |

## 3. 内置模板种子方案

内置模板（4 组代码模板 + 2 组工程模板，共 107 + N 个文件）**不手工搬运**，由一次性脚本从 `carlos-tools/src/main/resources/` 扫描生成 SQL：

```
输入：
  carlos-integration/carlos-tools/src/main/resources/codege/templates/{cloud-mybatis,cloud-ddd-mybatis,
      cloud-elasticsearch,cloud-mongo}/          # {template.xml, template/**}
  carlos-integration/carlos-tools/src/main/resources/projectge/project-templates/{carlos-springboot,
      carlos-springcloud}/                       # {template.xml, template/**}

处理：
  1. 读 template.xml → 解析 <name>/<describe>/<logicDeleteFields>/<versionFields>/<commonFields>
  2. 遍历 template/** → 每文件一条 dev_template，file_path 取相对 template/ 的路径
     - 扩展名 .ftl  → file_type=1，file_name 去掉 .ftl，含 "[for]" → loop_flag=true
     - 其他         → file_type=2
     - 文本文件 content 直接内联；二进制 → content_encoding=BASE64
  3. 转义单引号（'' ）、反斜杠；content 用 PG 的 dollar-quoting（$devkit$...$devkit$）包裹，
     避免 Freemarker 的 ${...} 与 SQL 拼接冲突

输出：
  carlos-framework-backend/docs/db/devkit_seed_templates.sql    # 幂等：
      INSERT ... SELECT ... WHERE NOT EXISTS (SELECT 1 FROM dev_template_group
                                              WHERE group_code = ? AND is_deleted = 0)
```

模板组编码映射（`group_code` ← 目录名，`group_name` 中文名）：

| 目录 | `group_code` | `group_name` | `template_type` | `tech_stack` | `db_type` |
|---|---|---|---|---|---|
| `codege/templates/cloud-mybatis` | `cloud-mybatis` | 微服务 MyBatis-Plus | 1 | `MYBATIS` | `ANY` |
| `codege/templates/cloud-ddd-mybatis` | `cloud-ddd-mybatis` | 微服务 DDD 四层 | 1 | `DDD_MYBATIS` | `ANY` |
| `codege/templates/cloud-elasticsearch` | `cloud-elasticsearch` | 微服务 Elasticsearch | 1 | `ELASTICSEARCH` | `ANY` |
| `codege/templates/cloud-mongo` | `cloud-mongo` | 微服务 MongoDB | 1 | `MONGO` | `ANY` |
| `projectge/project-templates/carlos-springboot` | `carlos-springboot` | Spring Boot 单体工程 | 2 | `SPRINGBOOT` | NULL |
| `projectge/project-templates/carlos-springcloud` | `carlos-springcloud` | Spring Cloud 微服务工程 | 2 | `SPRINGCLOUD` | NULL |

## 4. 菜单与权限种子

### 4.1 菜单（`sys_menu`）

一级菜单 + 6 个子页，`component` 遵循三层规则（顶层 `layout.base`、**中间层 `NULL`**、叶子 `view.{route_name}`）：

| route_name | route_path | component | 说明 |
|---|---|---|---|
| `devkit` | `/devkit` | `layout.base` | 一级目录「开发工具」 |
| `devkit_datasource` | `/devkit/datasource` | `view.devkit_datasource` | 数据源管理 |
| `devkit_codegen` | `/devkit/codegen` | `view.devkit_codegen` | 代码生成器 |
| `devkit_project` | `/devkit/project` | `view.devkit_project` | 工程生成器 |
| `devkit_template` | `/devkit/template` | `view.devkit_template` | 模板管理 |
| `devkit_template-editor` | `/devkit/template-editor` | `view.devkit_template-editor` | 模板编辑器（`hide_in_menu=true`，`active_menu=devkit_template`） |
| `devkit_record` | `/devkit/record` | `view.devkit_record` | 生成记录 |

`meta` 形如（对齐 `sys_favorite_menu.sql` 的写法）：

```json
{"title":"devkit_datasource","i18nKey":"route.devkit_datasource","icon":"lucide:database","order":1,"keepAlive":true}
```

> ⚠️ `sys_menu.meta.roles` 是**死字段**（动态路由下不生效），权限一律靠 `sys_operation.perm_code`。

### 4.2 权限点（`sys_operation`，`perm_code` 前缀 `devkit:`）

| perm_code | 名称 | 类型 |
|---|---|---|
| `devkit:datasource:view` / `:add` / `:edit` / `:delete` / `:test` | 数据源查看/新增/编辑/删除/测试连接 | `menu_id` 挂 `devkit_datasource` |
| `devkit:template:view` / `:add` / `:edit` / `:delete` / `:rollback` | 模板查看/新增/编辑/删除/版本回滚 | 挂 `devkit_template` |
| `devkit:codegen:preview` / `:generate` | 代码预览 / 生成下载 | 挂 `devkit_codegen` |
| `devkit:projectgen:preview` / `:generate` | 工程预览 / 生成下载 | 挂 `devkit_project` |
| `devkit:record:view` / `:delete` | 生成记录查看 / 删除 | 挂 `devkit_record` |

种子脚本 `devkit_seed_menu_operations.sql` 用 `id` 固定号段 `2113xxxxxxxxxxxxx`（`13` 为模块编码，参照 monitor 的 `1913…` 做法），幂等写法同 `seed_monitor_operations.sql`。
