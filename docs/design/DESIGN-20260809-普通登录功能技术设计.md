## 一、需求分析

### 1.1 业务需求

carlos-ui 当前采用纯 SSO 模式登录（重定向到 IdP 统一登录页）。用户希望：

1. **保留普通账号密码登录**：在 carlos-ui 登录页直接输入用户名密码完成登录
2. **SSO 作为可选方式**：保留"跳转到统一认证中心"的入口
3. **两者共存**：用户可在登录页自由切换

### 1.2 功能目标

| 目标       | 说明                                           |
|----------|----------------------------------------------|
| 普通登录     | 用户名 + 密码（SM2 加密传输），直接获取 Token                |
| 风控集成     | 登录前调用 `/auth/user/pre-check`，根据风险等级决定验证码/MFA |
| MFA 支持   | 密码验证通过后如需 MFA，弹出 TOTP 验证码输入框                 |
| 与 SSO 共存 | 登录页底部保留"统一认证登录"入口，点击跳转 IdP                   |
| 向后兼容     | 不影响现有 SSO 流程和 carlos-framework-portal        |


### 3.2 设计原则

1. **复用优先**：`UserLoginService.login()` 已包含完整认证逻辑，直接复用，不新增 Service
2. **安全不减配**：普通登录同样走 SM2 加密传输 + 风控 + MFA 链路
3. **不破坏 SSO**：所有改动为增量，不影响已有 SSO 流程
4. **前端保持本地登录体验**：密码在 carlos-ui 内收集，不走 IdP 页面跳转

## 四、后端改造设计

### 4.1 UserAuthController — 新增 login 端点

**文件**: `carlos-integration/carlos-auth/carlos-auth-service/src/main/java/com/carlos/auth/login/UserAuthController.java`

新增 `POST /auth/user/login` 端点：

```java
/**
 * 普通账号密码登录（JSON API）
 *
 * <p>SPA 直连登录入口，适用于不需要 SSO 的场景。
 * 支持 SM2 加密密码传输、风控预检、MFA step-up。</p>
 *
 * <p><strong>与 SSO 登录的区别：</strong></p>
 * <ul>
 *   <li>此端点：直接返回 JWT Token，不走浏览器重定向，不种 Session Cookie</li>
 *   <li>SSO 登录：走 /oauth2/authorize → /login（formLogin）→ Session → code → Token</li>
 * </ul>
 *
 * @param loginRequest 登录请求（含 SM2 加密密码）
 * @param httpRequest  HTTP 请求
 * @return 登录响应（Token 或 MFA 挑战）
 */
@Operation(summary = "普通账号密码登录", description = "JSON API 登录，直接返回 JWT Token")
@PostMapping("/login")
public Result<LoginResponse> login(@Valid @RequestBody LoginRequest loginRequest,
                                    HttpServletRequest httpRequest) {
    // 1. IP 速率限制（1分钟5次）
    String clientIp = ipLocationUtil.getClientIp(httpRequest);
    if (!RateLimitUtil.tryAcquire(AuthRedisKey.rateLogin(loginRequest.getUsername()), 5, 1, TimeUnit.MINUTES)) {
        return Result.error("登录请求过于频繁，请稍后再试");
    }

    // 2. 检查账号/IP 是否已被锁定
    if (loginService.isAccountLocked(loginRequest.getUsername())) {
        return Result.error("账号已被锁定，请30分钟后重试");
    }

    // 3. SM2 密码解密
    loginService.decryptPasswordIfNeeded(loginRequest);

    // 4. 执行登录认证（委托 UserLoginService）
    try {
        LoginResponse loginResponse = loginService.login(loginRequest);
        return Result.success(loginResponse);
    } catch (AuthenticationException e) {
        loginService.recordLoginFailure(loginRequest.getUsername(), httpRequest);
        throw e;
    }
}
```

### 5.1 pwd-login.vue — 重写为实际登录表单

**文件**: `carlos-ui/src/views/_builtin/login/modules/pwd-login.vue`

从"SSO 跳转按钮"改为"完整的用户名密码表单 + SSO 入口"：

```vue
<script setup lang="ts">
import { reactive, ref } from 'vue';
import { $t } from '@/locales';
import { loginModuleRecord } from '@/constants/app';
import { useRouterPush } from '@/hooks/common/router';
import { useAuthStore } from '@/store/modules/auth';
import { useCountDown } from '@sa/hooks';

defineOptions({ name: 'PwdLogin' });

const authStore = useAuthStore();
const { toLogin, toggleLoginModule } = useRouterPush();
const { loading, startLoading, endLoading } = useLoading();

const formRef = ref();
const form = reactive({
  userName: '',
  password: '',
  captchaToken: '',
  rememberMe: false,
});

// 是否需要验证码（根据 preCheck 结果）
const needCaptcha = ref(false);
const captchaType = ref<string | null>(null);

// 账号锁定倒计时
const { count, start: startCountDown, stop: stopCountDown } = useCountDown(60);

/**
 * 用户名失焦时触发预校验
 */
async function handleUserNameBlur() {
  if (!form.userName.trim()) return;

  const result = await authStore.preCheck(form.userName);
  if (result) {
    needCaptcha.value = result.needCaptcha || false;
    captchaType.value = result.captchaType || null;
  }
}

/**
 * 提交登录
 */
async function handleSubmit() {
  if (!formRef.value?.validate()) return;

  startLoading();

  try {
    // fetchLogin 内部处理 SM2 公钥获取 + 密码加密
    const { data, error } = await fetchLogin(form.userName, form.password);

    if (!error && data) {
      if (data.mfaRequired) {
        // 密码正确但需要 MFA
        authStore.mfaRequired = true;
        authStore.mfaToken = data.mfaToken;
        endLoading();
        return;
      }

      // 登录成功
      await authStore.loginByToken(data);

      if (form.rememberMe) {
        localStg.set('rememberedAccount', form.userName);
      }

      window.$notification?.success({
        title: $t('page.login.common.loginSuccess'),
        description: $t('page.login.common.welcomeBack')
      });

      await redirectFromLogin(true);
    } else {
      window.$message?.error($t('page.login.common.validateError'));
    }
  } catch (e) {
    // 错误由 request 拦截器统一处理
  } finally {
    endLoading();
  }
}

/**
 * SSO 登录：跳转到统一认证中心
 */
function handleSsoLogin() {
  toLogin();
}
</script>

<template>
  <AForm ref="formRef" :model="form" :rules="rules" @submit="handleSubmit">
    <AFormItem name="userName">
      <AInput
        v-model:value="form.userName"
        size="large"
        :placeholder="$t('page.login.common.userName')"
        @blur="handleUserNameBlur"
      >
        <template #prefix>
          <icon-ic-round-person />
        </template>
      </AInput>
    </AFormItem>

    <AFormItem name="password">
      <AInputPassword
        v-model:value="form.password"
        size="large"
        :placeholder="$t('page.login.common.password')"
        @press-enter="handleSubmit"
      >
        <template #prefix>
          <icon-ic-round-lock />
        </template>
      </AInputPassword>
    </AFormItem>

    <!-- 风控验证码（仅中/高风险时显示） -->
    <AFormItem v-if="needCaptcha" name="captchaToken">
      <CaptchaBox :type="captchaType" @verified="(token) => form.captchaToken = token" />
    </AFormItem>

    <div class="flex-y-center justify-between mb-16px">
      <ACheckbox v-model:checked="form.rememberMe">
        {{ $t('page.login.pwdLogin.rememberMe') }}
      </ACheckbox>
      <AButton type="link" @click="toggleLoginModule('reset-pwd')">
        {{ $t(loginModuleRecord['reset-pwd']) }}
      </AButton>
    </div>

    <AButton
      type="primary"
      html-type="submit"
      block
      size="large"
      shape="round"
      :loading="loading"
    >
      {{ $t('page.login.common.login') }}
    </AButton>

    <!-- 分割线 -->
    <ADivider>
      <span class="text-12px text-#999">{{ $t('page.login.common.otherWays') }}</span>
    </ADivider>

    <!-- SSO 统一认证入口 -->
    <AButton block size="large" @click="handleSsoLogin">
      <template #icon>
        <icon-ic-round-login />
      </template>
      统一认证登录
    </AButton>

    <div class="flex-y-center justify-between mt-12px">
      <AButton type="link" @click="toggleLoginModule('code-login')">
        {{ $t(loginModuleRecord['code-login']) }}
      </AButton>
      <AButton type="link" @click="toggleLoginModule('register')">
        {{ $t(loginModuleRecord.register) }}
      </AButton>
    </div>
  </AForm>
</template>
```

### 6.2 两种登录方式对比

| 维度             | 普通登录 (JSON API)         | SSO 登录 (OAuth2)                |
|----------------|-------------------------|--------------------------------|
| 入口             | `POST /auth/user/login` | `/oauth2/authorize` → `/login` |
| 密码收集位置         | carlos-ui SPA 内         | carlos-auth 的 Thymeleaf 表单页    |
| 传输方式           | SM2 加密 + HTTPS          | HTTPS（表单提交）                    |
| 响应方式           | JSON 返回 Token           | 浏览器重定向 + code 换 Token          |
| Session Cookie | 无（纯 Token）              | 有（IdP 域种 Session，实现 SSO）       |
| MFA            | 前端弹窗验证                  | IdP 页面验证                       |
| 适用场景           | 单系统使用、内网部署              | 多系统集成、统一入口                     |

## 七、安全设计

### 7.1 密码传输安全

```
前端                          后端
  │                             │
  │──1. GET /auth/public-key──►│  获取临时 SM2 公钥 (动态生成, 5min TTL)
  │◄──2. {publicKey, keyId}────│
  │                             │
  │──3. 前端 SM2 加密───────────│
  │   cipher = SM2.encrypt(     │
  │     password, publicKey)    │
  │                             │
  │──4. POST /auth/user/login──►│
  │   {password: cipher,        │
  │    keyId: "xxx"}            │
  │                             │──5. 根据 keyId 查私钥
  │                             │──6. SM2 解密得明文
  │                             │──7. Argon2id 哈希比对
  │                             │──8. 销毁本次临时密钥对
```

- SM2 密钥对每次获取时动态生成，5 分钟 TTL（Redis 存储私钥）
- HTTPS + SM2 双重加密（纵深防御）
- 密码明文不出现在任何日志中

### 7.2 防暴力破解

| 层级    | 机制        | 参数          |
|-------|-----------|-------------|
| 账号维度  | 失败计数 + 锁定 | 5 次 / 30 分钟 |
| IP 维度 | 失败计数 + 封禁 | 20 次 / 1 小时 |
| 接口维度  | 速率限制      | 5 次/分钟/账号   |
| 预校验   | 提前感知风险    | 不泄露账号存在性    |

### 7.3 MFA 集成

- 密码验证通过后，`UserLoginService.login()` 自动判断是否需要 MFA
- 需要 MFA → 返回 `mfaToken`（5 分钟 TTL 临时令牌）+ `mfaRequired: true`
- 前端弹出 MfaVerify 弹窗，用户输入 TOTP 验证码
- 调用 `/auth/mfa/step-up-verify` 完成二次验证
- 签发正式 Token，JWT Claims 中 `aal=2`、`auth_method=password+totp`

### 7.4 CSRF 防护

`/auth/user/login` 是纯 JSON API（非浏览器表单），**不需要 CSRF Token**。已在 SecurityConfig 中 ignore。

## 八、与 SSO 的关系

### 8.1 定位

| 登录方式                         | 定位             | 适用对象               |
|------------------------------|----------------|--------------------|
| 普通登录 (`/auth/user/login`)    | **内部系统快速登录**   | carlos-ui 管理员、日常开发 |
| SSO 登录 (`/oauth2/authorize`) | **统一入口、跨系统免密** | 多系统用户、需要单点登录       |

### 8.2 共存策略

在登录页 pwd-login.vue 中：

```
┌──────────────────────────────┐
│  ┌──────────────────────────┐│
│  │ 用户名                    ││
│  │ 密码                      ││
│  │ [登录按钮]                ││  ← 普通密码登录
│  └──────────────────────────┘│
│                              │
│  ────── 或 ──────────────   │
│                              │
│  ┌──────────────────────────┐│
│  │ [统一认证登录]             ││  ← SSO 入口
│  └──────────────────────────┘│
└──────────────────────────────┘
```

普通登录成功后同样获得 JWT Token，后续 API 调用与 SSO 登录完全相同。

### 8.3 不影响现有流程

- `carlos-framework-portal` 仍然走 OAuth2 PKCE（不作任何改动）
- IdP `/login` 页面（Thymeleaf）仍然可用
- Gateway 的 Token 校验逻辑完全不感知登录方式
- `SecurityContext`、`UserContext` 下游注入行为不变
