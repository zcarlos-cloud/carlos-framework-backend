## 一、总体架构

```
┌──────────────────────────────────────────────────────────────────────┐
│  客户端浏览器                                                            │
│  ┌─────────────────────┐    ┌─────────────────────┐                   │
│  │ carlos-ui (:5173)   │    │ carlos-framework-portal (:5200)│                  │
│  │ 管理后台 SPA         │    │ 应用门户 (SSO入口)     │                  │
│  │ SSO + PKCE          │    │ SSO + PKCE           │                  │
│  └──────┬──────────────┘    └──────┬──────────────┘                   │
│         │ OAuth2 authorize         │ OAuth2 authorize                  │
│         ▼                          ▼                                   │
│  ┌─────────────────────────────────────────┐                          │
│  │   carlos-auth (IdP :9511)               │                          │
│  │   Spring Authorization Server 2.x       │                          │
│  │   Form Login → OAuth2 Authorization Code│                          │
│  │   JWT 签发 (RS256, Redis 存储)           │                          │
│  └────────────────────┬────────────────────┘                          │
│                       │ Feign ApiOrgUser                                │
│                       ▼                                                │
│  ┌─────────────────────────────────────────┐                          │

│  │   org_user 表 (account/pwd/phone/email) │                          │
│  └─────────────────────────────────────────┘                          │
│                                                                        │
│  API 调用链路:                                                          │
│  客户端 ──Bearer JWT──▶ carlos-gateway (:9510) ──X-* Headers──▶ 下游微服务 │
│                         JWT验证/RBAC鉴权         security-starter 解析    │
└──────────────────────────────────────────────────────────────────────┘
```

### 核心认证流程

```
1. 用户访问 SPA → 点击登录
2. SPA 生成 PKCE (code_verifier + code_challenge S256) + state
3. 302 跳转 → IdP /oauth2/authorize?response_type=code&code_challenge=...&state=...
4. IdP 未登录 → 显示 Thymeleaf 登录页 (POST /login)
5. 表单登录 → PasswordDecryptFilter(SM2解密) → DaoAuthenticationProvider → FormLoginSuccessHandler
6. 登录成功 → SavedRequestAware 恢复 /oauth2/authorize → 签发 authorization_code
7. 302 回调 → SPA /oauth2/callback?code=xxx&state=xxx
8. SPA 校验 state → POST /oauth2/token (code + code_verifier) → 获取 access_token + refresh_token
9. Token 存 localStorage → 后续请求 Authorization: Bearer <token>
```

## 三、授权服务器 (carlos-auth)

### 安全配置

**两条 SecurityFilterChain**：

| 链          | Order              | 匹配路径                                         | 说明                               |
|------------|--------------------|----------------------------------------------|----------------------------------|
| OAuth2 授权链 | HIGHEST_PRECEDENCE | `/oauth2/**`, `/.well-known/**`, `/userinfo` | 所有请求需认证，CSRF 部分忽略                |
| 默认链        | 2                  | 其余所有                                         | formLogin + oauth2ResourceServer |

**密码体系**：Argon2id (默认) + BCrypt 兼容 + SM4 遗留迁移 + Pepper
**密码传输**：SM2 国密加密 (`PasswordDecryptFilter`)
**Token**：JWT (RS256) + OPAQUE (可切换)，存入 Redis 非数据库

### Token 存储 (Redis Key 设计)

| Key                                    | 用途               |
|----------------------------------------|------------------|
| `oauth2:state:{state}`                 | 授权 state         |
| `oauth2:code:{code}`                   | 授权码              |
| `oauth2:access_token:{token}`          | 访问令牌             |
| `oauth2:refresh_token:{token}`         | 刷新令牌             |
| `oauth2:id:{id}`                       | 授权 ID            |
| `oauth2:user_sessions:{principalName}` | 用户会话 Set (全局登出用) |

## 五、资源服务器 (security-starter)

### 认证流程

`UserContextAuthenticationFilter` (OncePerRequestFilter)：

1. 白名单检查 → 跳过
2. 读取 `X-User-Id` → 无则跳过
3. IP 可信源检查 (`trustedIpRanges`)
4. 解析 `X-User-Roles` → 加载权限 (`PermissionProvider`)
5. 构建 `UserContext` → 设置 `SecurityContextHolder`

### 权限缓存

```
Caffeine L1 (本地) → Redis L2 (auth:permissions:{roleId}, 7天TTL) → DB L3
                                     ↕
                          Redis Pub/Sub (auth:permission:change) 跨实例同步
```
