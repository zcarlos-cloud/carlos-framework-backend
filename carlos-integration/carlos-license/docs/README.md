## 命名规范

### 文件命名

```
# 产品需求
PRD-{YYYYMMDD}-{需求简称}.md
例: PRD-20260520-许可证有效期策略.md

# 架构设计
ARCH-{主题}-{版本}.md
例: ARCH-授权验证架构-v1.0.md

# 接口设计
API-{模块}-{版本}.md
例: API-license-v1.0.md

# 测试计划
TESTPLAN-{迭代}-{版本}.md
例: TESTPLAN-Sprint3-v1.0.md

# 缺陷报告
BUG-{YYYYMMDD}-{NNN}.md
例: BUG-20260520-001.md

# 架构决策
ADR-{NNN}-{标题}.md
例: ADR-001-许可证加密算法选型.md
```

## 文档生命周期

```
草稿 → 评审中 → 已确认 → 已归档
         ↓         ↓
       已拒绝    已废弃
```

每篇文档必须在头部标注当前状态、版本、作者和日期。
