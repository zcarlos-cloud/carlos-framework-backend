## 一、模块概

| 子模                    | 职责                                                                 |
|-----------------------|--------------------------------------------------------------------|
| `carlos-auth-api`     | Feign 接口、AO/Param、Fallback、错误码                                     |
| `carlos-auth-boot`    | 单体启动入口（排DataSource                                                 |
| `carlos-auth-cloud`   | 微服务启动入                                                             |
| `carlos-auth-service` | 业务实现层（OAuth2、IdP、MFA、Audit、Captcha、Login、Provider、Security、Web、App |

**carlos-auth-service 主要*

- `idp/`：统一身份源抽象（`IdentityProvider`、`LocalIdentityProvider`、`SmsCodeIdentityProvider`
- `oauth2/`：OAuth2 授权服务器（client/config/grant/handler/repository/server/user
- `mfa/`：多因素认证（TOTP、Recovery Code、Trusted Device
- `audit/`：安全告警（SecurityAlert
- `captcha/`：短邮件验证
- `login/`：用户登录入口（`UserAuthController`、`UserLoginService`
- `provider/`：业务侧用户数据接入（`UserProvider`、`DefaultUserProvider`
- `security/`：Spring Security 扩展（ext/handle/manager/service
- `web/`：通用 Web 接口（`TokenController`、`PasswordApi`
- `app/`：OAuth2 客户端应用管理（CRUD
- `util/`：工具类（DeviceFingerprint、IpLocationUtil、QrCodeGenerator、SensitiveDataUtil
- `config/`、`exception/`：配置与异常
