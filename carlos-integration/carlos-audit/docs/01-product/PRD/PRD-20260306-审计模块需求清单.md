## 7. 验收标准 (Acceptance Criteria)

### 7.1 功能验收

| ID     | 验收   | 验收标准                                         |
|--------|------|----------------------------------------------|
| AC-001 | 注解拦截 | 使用 `@AuditLog` 注解的方法被调用后，ClickHouse 中应存在对应记录 |
| AC-002 | 异步性能 | 异步模式下，接口响应时间增加 < 1ms                         |
| AC-003 | 批量写入 | 500 条数据批量写ClickHouse 耗时 < 100ms              |
| AC-004 | 查询功能 | 分页查询 100 万条数据响应时间 < 100ms                    |
| AC-005 | 租户隔离 | 租户 A 无法查询到租B 的数                              |
| AC-006 | 配置生效 | 修改配置后，新配置在 30 秒内生效                           |

### 7.2 性能验收

| ID     | 验收   | 验收标准                      |
|--------|------|---------------------------|
| AC-007 | 压力测试 | 单机 10TPS 持续 10 分钟，系统无 OOM |
| AC-008 | 内存稳定 | 持续运行 7 天，内存使用稳定4GB 以内     |
| AC-009 | 查询并发 | 支持 100 并发查询，响应时< 1s       |
| AC-010 | 故障恢复 | ClickHouse 故障恢复后，数据可正常写   |

### 7.3 安全验收

| ID     | 验收     | 验收标准             |
|--------|--------|------------------|
| AC-011 | SQL 注入 | 通过 SQLMap 扫描无高危漏 |
| AC-012 | 越权访问   | 未授权用户无法访问审计数     |
| AC-013 | 数据脱敏   | 敏感字段在日志和接口返回中均已脱 |
| AC-014 | 传输安全   | 所有接口仅支持 HTTPS 访问 |

### 7.4 文档验收

| ID     | 验收   | 验收标准                     |
|--------|------|--------------------------|
| AC-015 | 接口文档 | Swagger 文档完整，包含所有接口和参数说明 |
| AC-016 | 架构文档 | 架构设计文档通过评审               |
| AC-017 | 部署文档 | 提供详细的部署和配置指南             |
| AC-018 | 操作手册 | 提供常见问题排查手册               |
