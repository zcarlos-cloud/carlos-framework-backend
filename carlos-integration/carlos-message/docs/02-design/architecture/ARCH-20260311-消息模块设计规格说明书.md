## 1. 引言

### 1.1 编写目的

本文档为 Carlos Message 统一消息中心模块的详细设计规格说明书，用于指导开发人员进行系统实现。

### 1.2 适用范围

- 消息中心服务端开发
- 消息客户端 SDK 开发
- 渠道适配器开发
- 管理后台开发

### 1.3 术语定义

| 术语   | 说明                                                              |
|------|-----------------------------------------------------------------|
| 消息模板 | 预定义的消息内容格式，支持 FreeMarker 变量占位符                                  |
| 渠道   | 消息发送通道，如短信、邮件、钉钉等                                               |
| 优先级  | 消息发送的优先级，影响队列处理顺序（1-紧急 2-高 3-普通 4-低）                            |
| 消息状态 | 消息在生命周期中的状态（PENDING/SENDING/SENT/DELIVERED/READ/FAILED/REVOKED） |
| 渠道状态 | 渠道可用状态（0-禁用 1-启用 2-故障）                                          |

## 3. 详细设计

### 3.1 数据模型设计

（表结构同 v1.0，详见数据库设计文档，此处补充新增字段说明）

#### message_channel 补充说明

| 字段               | 类型      | 说明                 |
|------------------|---------|--------------------|
| rate_limit_qps   | INT     | 每秒最大请求数            |
| rate_limit_burst | INT     | 突发流量限制             |
| retry_times      | TINYINT | 最大重试次数             |
| retry_interval   | INT     | 重试间隔(ms)           |
| weight           | INT     | 负载均衡权重（同类型多服务商时生效） |
| is_enabled       | TINYINT | 0-禁用 1-启用 2-故障     |

#### message_receiver 状态流转

状态流转：PENDING(0) -> SENDING(1) -> SENT(2) -> DELIVERED(3) -> READ(4)
| |
+------------> FAILED(5) -> (重试<3次回到 SENDING)
|
+------------> REVOKED(6)

常用查询场景：

```sql
-- 1. 查询某人的待发送消息
SELECT * FROM message_receiver
WHERE receiver_id = ? AND status = 0
ORDER BY create_time DESC;
-- 使用索引: idx_receiver_status

-- 2. 查询某条消息的所有接收人状态
SELECT * FROM message_receiver
WHERE message_id = ?
ORDER BY create_time;
-- 使用索引: idx_message_id

-- 3. 查询某渠道的失败记录（用于重试）
SELECT * FROM message_receiver
WHERE channel_code = ? AND status = 5 AND fail_count < 3
ORDER BY create_time
LIMIT 100;
-- 使用索引: idx_channel_status

-- 4. 查询定时发送队列
SELECT * FROM message_receiver
WHERE status = 0 AND schedule_time <= NOW()
ORDER BY schedule_time
LIMIT 1000;
-- 使用索引: idx_schedule
```

public interface ChannelAdapter {
    String getChannelCode();
    ChannelType getChannelType();
    boolean isAvailable();
    SendResult send(MessageContext context);
    default List<SendResult> sendBatch(List<MessageContext> contexts) { ... }
    boolean supports(String messageType);
    default boolean healthCheck() { return isAvailable(); }
}

public abstract class AbstractChannelAdapter implements ChannelAdapter, InitializingBean {
    protected final MessageChannelManager messageChannelManager;
    protected MessageChannelDTO channelConfig;

    @Override
    public void afterPropertiesSet() {
        ChannelFactory.register(this);
    }

    @Override
    public boolean isAvailable() {
        if (channelConfig == null) loadChannelConfig();
        return channelConfig != null && Objects.equals(channelConfig.getEnabled(), 1);
    }

    public void refreshConfig() {
        loadChannelConfig();
    }

    protected abstract SendResult doSend(MessageContext context);
}
```

@Component
@RequiredArgsConstructor
public class RedisStreamMessageQueue implements MessageQueue {
    private final StringRedisTemplate stringRedisTemplate;
    private final MessageProperties messageProperties;
    private final ObjectMapper objectMapper;

    @Override
    public void enqueue(MessageContext context, int priority) { ... }

    @Override
    public void delay(MessageContext context, long delayMillis) {
        double score = computePriorityScore(System.currentTimeMillis() + delayMillis, context.getPriority());
        stringRedisTemplate.opsForZSet().add(DELAY_ZSET_KEY, json, score);
    }

    @Override
    public void schedule(MessageContext context, LocalDateTime scheduleTime) { ... }

    @Override
    public void consumeBatch(int priority, int batchSize, Consumer<List<MessageContext>> handler) { ... }

    private double computePriorityScore(long timestamp, Integer priority) {
        int p = priority != null ? priority : 3;
        return timestamp * 100L + p;
    }
}
```

## 4. 安全设计

### 4.1 接口安全

- **鉴权**: 所有接口需携带有效 Token
- **签名**: 关键接口需进行参数签名
- **限流**: 按应用/接口维度限流
- **IP白名单**: 渠道回调接口限制IP

### 4.2 内容安全

- **敏感词过滤**: 使用 DFA 算法进行敏感词检测
- **内容审计**: 营销类消息人工审核
- **频率控制**: 单用户单渠道发送频率限制（60秒5条）
- **指纹去重**: MD5 内容指纹，5分钟内相同内容不重复发送

### 4.3 数据安全

- **加密存储**: 渠道配置敏感字段加密
- **脱敏展示**: 手机号、邮箱等脱敏展示
- **审计日志**: 所有操作记录审计日志

## 5. 监控告警

### 5.1 监控指标

| 指标                     | 说明      | 类型      | 标签              |
|------------------------|---------|---------|-----------------|
| message.send.total     | 发送总量    | Counter | channel, result |
| message.send.duration  | 发送耗时    | Timer   | channel, result |
| message.send.active    | 当前活跃发送数 | Gauge   | -               |
| message.queue.size     | 队列长度    | Gauge   | priority        |
| message.retry.total    | 重试次数    | Counter | channel         |
| message.channel.health | 渠道健康状态  | Gauge   | channel         |

### 5.2 告警规则

- **渠道故障**: 单个渠道连续 3 次健康检查失败，自动标记为故障状态（2），并推送 WebSocket 告警
- **队列积压**: 队列积压 > 10000，持续 3 分钟
- **发送延迟**: 消息发送 p99 延迟 > 3s
- **系统异常**: 异常率 > 10/分钟
