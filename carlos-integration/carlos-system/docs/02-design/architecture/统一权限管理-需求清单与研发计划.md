> 日期: 2026-05-26
> 状态: 待评审

---

## 一、项目概述

### 1.1 背景

当前系统权限管理存在数据冗余、前后端权限不一致、无统一权限码桥梁等问题。`sys_resource` 与 `sys_menu_operate` 两份数据不同步，
`sys_resource` 数据不被鉴权逻辑消费。前端按钮权限与后端 API 授权无关联关系。

### 1.2 范围

**本次改造涉及模块：**

- `carlos-system-bus`（菜单、操作权限、角色权限）
- `carlos-system-api`（Feign 接口调整）
- `carlos-auth`（JWT Token 精简）
- `carlos-gateway`（网关鉴权兼容）
- `carlos-spring-boot-starter-web`（资源扫描存储目标变更）
- `carlos-spring-boot-starter-security`（权限缓存优化）
- `carlos-ui`（前端路由、按钮权限、权限管理页面）

**不涉及：**

- 三方平台授权（已在方案中明确排除）
- 多租户权限隔离改造（保持现状）

### 1.3 核心模型

| 表                    | 说明                                                     |
|----------------------|--------------------------------------------------------|
| `sys_menu`           | 前端导航菜单树，纯展示，不承载权限语义                                    |
| `sys_operation`      | 统一操作表：按钮(op_type=1) + API(op_type=2)，`perm_code` 为权限桥梁 |
| `org_role_operation` | 角色-操作关联，角色授权的核心关联表                                     |
