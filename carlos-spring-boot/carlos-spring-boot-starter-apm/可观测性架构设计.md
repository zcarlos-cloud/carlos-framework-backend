## 1. 背景与目标

### 1.1 设计目标

1. **渐进式可观测性**：零 Agent 部署时，日志层面完整可追踪；部署 SkyWalking 后自动增强
2. **技术栈统一**：Gateway 与下游微服务使用相同的传播协议和追踪模型
3. **协议兼容**：优先 B3（Brave 原生），同时透传 sw8（SkyWalking）
4. **精简模型**：业界标准 traceId + spanId，不引入多余的 requestId 概念

### 1.2 核心设计决策

| 决策                     | 说明                                                    |
|------------------------|-------------------------------------------------------|
| traceId + spanId 模型    | 与 OpenTelemetry / SkyWalking / Zipkin 对齐，不设 requestId |
| Brave 作为兜底             | 无 Agent 时提供完整的方法级追踪和 B3 传播                            |
| SkyWalking Agent 自动增强  | 有 Agent 时接管 Span 上报和可视化，Brave Span 被自动关联              |
| Gateway 直接操作 Brave API | WebFlux 不走 Servlet Filter，需显式创建 Span                  |

## 2. 三层可观测性架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       渐进式可观测性架构                                   │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  Layer 3: SkyWalking APM（可选部署）                              │   │
│  │  - 服务拓扑图 / 性能剖析 / JVM 监控 / 告警                         │   │
│  │  - SkyWalkingDetector 自动检测 Agent 存在后激活                    │   │
│  │  - Agent 不存在时：完全不生效，零损耗                               │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  Layer 2: 分布式链路追踪（内置，Brave / Micrometer Tracing）       │   │
│  │  - Span 创建与方法级追踪（@TraceTag 注解）                         │   │
│  │  - B3 协议跨服务传播（单头 + 多头）                                 │   │
│  │  - Feign 拦截器自动透传 B3                                         │   │
│  │  - 响应头返回 X-Trace-ID + X-Span-ID                              │   │
│  │  ▲ 始终启用，框架内置                                               │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  Layer 1: 日志关联（基础，始终启用）                                │   │
│  │  - MdcFilter 注入 traceId / spanId 到 MDC                        │   │
│  │  - 统一 logback 格式 [traceId-spanId]                              │   │
│  │  - 支持 grep traceId 串起全链路日志                                 │   │
│  │  ▲ 始终启用，开箱即用                                               │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.1 SkyWalking 自动检测机制

```
服务启动
    │
    ├── SkyWalkingDetector 检查 AgentBoot 类是否存在
    │
    ├── Agent 不存在 → Layer 1 + Layer 2 工作
    │     TraceUtil.getTraceId() → Brave → MDC 兜底
    │
    └── Agent 存在 → Layer 1 + Layer 2 + Layer 3 工作
          TraceUtil.getTraceId() → SkyWalking → Brave → MDC
          SkyWalking Agent 自动接管 Span 上报和可视化
```

## 3. 核心数据流

### 3.1 完整请求链路

```
Client
  │
  ▼
┌──────────────────────────────────────────────────────┐
│                  carlos-gateway                       │
│                                                       │
│  RequestTracingFilter (Order -9000)                    │
│  ┌─────────────────────────────────────────────────┐ │
│  │ 1. extractB3Context() — 从入站提取 B3 头          │ │
│  │ 2. tracer.nextSpan() — 创建或继续 Span            │ │
│  │ 3. injectPropagationHeaders():                   │ │
│  │    - X-Trace-ID:   traceId                       │ │
│  │    - b3:           {traceId}-{spanId}-1          │ │
│  │    - X-B3-TraceId: traceId (多头条兼容)           │ │
│  │    - X-B3-SpanId:  spanId                        │ │
│  │    - sw8:          透传（如有）                   │ │
│  │ 4. 响应头: X-Trace-ID, X-Span-ID                  │ │
│  └─────────────────────────────────────────────────┘ │
│                                                       │
│  AccessLogFilter (Order 1000)                          │
│  - method|path|status|duration|traceId|clientIp       │
└──────────┬───────────────────────────────────────────┘
           │ B3 头传播
           ▼
┌──────────────────────────────────────────────────────┐
│              下游微服务 (carlos-starter-apm)           │
│                                                       │
│  MdcFilter (Order HIGHEST_PRECEDENCE)                  │
│  ┌─────────────────────────────────────────────────┐ │
│  │ 1. resolveTraceId(): B3单头 → B3多头 → sw8       │ │
│  │                      → X-Trace-ID → 生成新的      │ │
│  │ 2. resolveSpanId():  B3单头 → B3多头 → 生成新的   │ │
│  │ 3. MdcUtil.setTraceId() / setSpanId()            │ │
│  │ 4. MdcUtil.setTraceIdFromBrave() — Brave 覆盖    │ │
│  │ 5. MdcUtil.setSkyWalkingTraceIdIfPresent()       │ │
│  │ 6. 响应头: X-Trace-ID                             │ │
│  │ 7. finally: MdcUtil.clear()                      │ │
│  └─────────────────────────────────────────────────┘ │
│                                                       │
│  业务代码: TraceUtil.getTraceId() → 日志输出            │
│                                                       │
│  Feign 调用 → TracingFeignInterceptor                  │
│  ┌─────────────────────────────────────────────────┐ │
│  │ propagateTraceId():   X-Trace-ID                 │ │
│  │ propagateB3Headers(): b3={traceId}-{spanId}-1    │ │
│  └─────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

### 3.2 Trace ID 获取优先级

```
TraceUtil.getTraceId()
    │
    ├── Layer 3: SkyWalking Agent (如果检测到)
    │     └── TraceContext.traceId() → 返回 sw traceId
    │
    ├── Layer 2: Brave (内置，始终可用)
    │     └── tracer.currentSpan().context().traceIdString()
    │
    └── Layer 1: MDC 兜底
          └── MDC.get("traceId")
```

## 4. 协议传播策略

### 4.1 传播头一览

| Header         | 协议         | 格式                     | 生成方          | 说明        |
|----------------|------------|------------------------|--------------|-----------|
| `b3`           | B3 单头      | `{traceId}-{spanId}-1` | Gateway      | 主传播协议     |
| `X-B3-TraceId` | B3 多头      | hex                    | Gateway      | 兼容旧版      |
| `X-B3-SpanId`  | B3 多头      | hex                    | Gateway      | 兼容旧版      |
| `X-Trace-ID`   | 自定义        | hex                    | Gateway + 下游 | 日志追踪兜底    |
| `sw8`          | SkyWalking | 透传不解码                  | 不生成          | Agent 层处理 |

### 4.2 协议分工

| 场景                   | 使用的协议                               |
|----------------------|-------------------------------------|
| Gateway → 下游服务       | B3 单头（主）+ B3 多头（兼容）+ X-Trace-ID（兜底） |
| 下游服务 → 更深层服务 (Feign) | B3 单头 + X-Trace-ID                  |
| SkyWalking Agent 已部署 | Agent 自动通过 sw8 跨进程传播（字节码层）          |
| 人工日志追踪               | grep X-Trace-ID 或 traceId           |

## 5. 模块分工

|                   | **carlos-gateway**                  | **carlos-spring-boot-starter-apm** |
|-------------------|-------------------------------------|------------------------------------|
| **角色**            | 链路入口，创建 Root Span                   | 链路中间节点，继续 Span                     |
| **运行时**           | WebFlux (Reactor)                   | Servlet (Tomcat)                   |
| **过滤器**           | RequestTracingFilter (GlobalFilter) | MdcFilter (Servlet Filter)         |
| **Span 管理**       | 直接操作 Brave API                      | 通过 Micrometer Tracing + Brave 自动   |
| **响应头**           | X-Trace-ID + X-Span-ID              | X-Trace-ID                         |
| **SkyWalking 检测** | 无                                   | SkyWalkingDetector 自动检测            |
| **对外 API**        | 无                                   | TraceUtil + MdcUtil                |

## 6. 依赖说明

### 6.1 Gateway 依赖

```xml
<!-- Micrometer Tracing + Brave 自动装配（Tracer/Sampler/Propagator Bean） -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-micrometer-tracing-brave</artifactId>
</dependency>

<!-- Brave 核心库（brave.Tracer / brave.Span / TraceContext），非传递依赖，须显式声明 -->
<dependency>
    <groupId>io.zipkin.brave</groupId>
    <artifactId>brave</artifactId>
</dependency>
```

### 6.2 APM Starter 依赖

```xml
<!-- Micrometer Tracing + Brave 桥接（传递引入 brave + brave-context-slf4j + 传播工具） -->
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-tracing-bridge-brave</artifactId>
</dependency>

<!-- SkyWalking Toolkit（optional，有 Agent 时才用到） -->
<dependency>
    <groupId>org.apache.skywalking</groupId>
    <artifactId>apm-toolkit-trace</artifactId>
    <optional>true</optional>
</dependency>
```

## 7. 配置说明

### 7.1 APM 配置 (carlos-starter-apm)

```yaml
carlos:
  apm:
    enabled: true

    # Layer 1: MDC 日志关联
    mdc:
      enabled: true
      trace-id-key: traceId
      span-id-key: spanId
      add-to-response: true        # 响应头返回 X-Trace-ID
      response-header-name: X-Trace-ID

    # Layer 2: Brave 链路追踪
    tracing:
      enabled: true
      sample-rate: 1.0             # 采样率 (0.0-1.0)
      propagation: B3_SINGLE       # B3_SINGLE / B3_MULTI

    # Layer 3: SkyWalking 增强
    skywalking:
      enabled: AUTO                # AUTO / true / false
      takeover: true               # Agent 存在时接管 Trace ID
      enrich-log: true             # 日志打印 tid

    # Feign 传播
    feign:
      enabled: true
```

### 7.2 Gateway 配置

```yaml
carlos:
  gateway:
    tracing:
      enabled: true
      propagation: B3_SINGLE       # B3_SINGLE / B3_MULTI / ALL
      sw8-propagation: true        # 透传入站 sw8 头
      sampling-rate: 1.0
      ignore-patterns:
        - /actuator/**
        - /health
```

## 9. 术语表

| 术语          | 说明                                    |
|-------------|---------------------------------------|
| **B3**      | Zipkin 的分布式追踪传播协议                     |
| **sw8**     | SkyWalking 跨进程传播协议 v8                 |
| **MDC**     | Mapped Diagnostic Context，SLF4J 线程上下文 |
| **Trace**   | 一次完整的请求链路                             |
| **Span**    | 链路中的一个操作单元                            |
| **traceId** | 全局唯一，跨服务不变                            |
| **spanId**  | 每跳变化，标识具体操作                           |
